# Portfolio Web — Dennis David Anchundia

Sitio web de portafolio personal: presenta mis habilidades, proyectos y contacto.
Construido con el stack moderno de backend demandado por la industria.

## Stack

- **Backend:** Java 21, Spring Boot 4 (MVC, Data JPA, Security, Validation, Cache, Actuator)
- **Base de datos:** PostgreSQL 16, Redis 7, Flyway
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, TanStack Query, i18n
- **Infraestructura:** Docker, docker-compose, Kubernetes (Kustomize), GitHub Actions
- **Calidad:** JUnit 5, Mockito, Testcontainers

## Estructura del repositorio

```
├── backend/    # API REST Spring Boot
├── frontend/   # SPA React + TypeScript
├── docker/     # Dockerfiles, docker-compose, nginx
├── k8s/        # Manifiestos Kubernetes
├── docs/       # Documentación
└── .github/    # Workflows de CI/CD
```
